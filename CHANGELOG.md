# Histórico de alterações

## 15/10/2026 · MVP na Cloudflare

O MVP passa a ter build próprio para Cloudflare Workers, com ambientes de
produção e desenvolvimento separados. A publicação identifica a versão
instalada. As páginas protegidas redirecionam acessos sem sessão para o login.
O fluxo de desenvolvimento também permite publicação manual pelo GitHub Actions.

## 15/10/2026 · Publicação por versão aprovada

A publicação WAY exige o SHA completo aprovado. O README descreve os workflows,
a ordem de execução e a conferência da instalação. Os exemplos de configuração
usam variáveis e placeholders.

## 15/10/2026 · Avisos de produção

Toda publicação em produção na WAY avisa o grupo. O resultado do envio aparece
em um job próprio. Os cartões mantêm projeto, branch, status, mensagem e commit,
com os indicadores de sucesso e falha.
