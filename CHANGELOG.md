# Histórico de alterações

## 15/10/2026 · Publicação WAY com versão explícita

O README orientava a publicação sem distinguir a WAY do MVP. Agora o procedimento
mostra os workflows corretos, a ordem API e frontend e como conferir a instalação.
O fluxo WAY de produção passa a exigir o SHA completo aprovado e recusa uma
versão vazia ou fora do formato antes do checkout e da autenticação AWS.
Os exemplos de acesso usam variáveis ou placeholders, sem senhas e hashes prontos.
